# Go Labs

Base de conhecimento sobre **Go** do Caramelo Tech - uma linguagem simples, rápida e feita para construir software confiável. Sua jornada com Go começa aqui.

## O que você vai encontrar

- **Fundamentos** - seus primeiros passos com Go: preparar o ambiente, entender o que é a linguagem e escrever os primeiros programas. É por aqui que se começa.
- **Prática** - exercícios e projetos para colocar a mão no código e fixar o que foi estudado.
- **Roadmap** - a trilha de estudos de Go, do primeiro programa à produção, para você saber o que estudar e em que ordem.
- **Recursos** - materiais externos para aprofundar cada assunto.

Navegue pelas seções na barra lateral. Se está começando, comece por Fundamentos.

## Além das notas

O repositório [go-labs](https://github.com/caramelotech/go-labs) também contém exemplos de código prontos para executar na pasta `examples/`.
